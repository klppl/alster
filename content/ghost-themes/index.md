## A small collection

This sample folder shows how Alster handles a project with several write-ups. Images and downloads live beside the Markdown files.

Start with [the Fieldnotes theme](fieldnotes.md), or add another Markdown file to this folder.

## A few constraints

Readable type. Enough space between paragraphs. Navigation that stays out of the way.

These are starter examples, ready to replace with your own work.
